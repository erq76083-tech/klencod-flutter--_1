# أمان | AMAN Pro — النظام المتكامل للرقابة الأبوية والاقتران الكامل والرادار الجغرافي

تطبيق **أمان (AMAN Pro)** المتكامل لإدارة وحماية هاتف الطفل عن بُعد بأعلى دقة، مع الحفاظ الكامل على منظومة التخزين المحلي (`SQLite / sqflite` + `SharedPreferences`) ودعم الاقتران المباشر الفوري بين الهاتفين.

## أبرز المميزات والتحديثات الشاملة
1. **منظومة الاقتران الكامل بين الهاتفين (Dual-Phone Full Pairing)**:
   - اقتران فوري عبر **كود الاقتران السداسي** ومصفوفة **QR التفاعلية**.
   - محرك اتصال شبكي مباشر (`WebSocket P2P` على المنفذ `45455` + اكتشاف تلقائي عبر `UDP` على المنفذ `45454`) للربط اللحظي عبر نفس شبكة Wi-Fi أو نقطة الاتصال الشخصية (Hotspot).
   - دعم حزم المزامنة المشفرة (`SHA-256 + Base64 Sync Token`) للمزامنة عبر الشبكات المختلفة وبيانات الهاتف.
2. **التحكم الكامل في جميع التطبيقات والنظام على هاتف الطفل**:
   - حظر/سماح فوري لأي تطبيق، وتحديد الحد اليومي بالدقائق، وجدول الساعات المسموحة.
   - قيود دقيقة لكل تطبيق: قطع الإنترنت عن التطبيق، كتم الإشعارات، منع إلغاء التثبيت، وطلب رمز PIN الأبوي عند الفتح.
   - قفل فوري شامل لهاتف الطفل (Master Lock) مع رسالة شاشة قفل مخصصة، وتشغيل صافرة الإنذار الصوتية عن بُعد، وإرسال رسائل منبثقة فورية لشاشة الطفل.
   - التحكم في العتاد والشبكة والويب: تعطيل الكاميرا والميكروفون، قفل المتجر ومنع تثبيت التطبيقات، قفل إعدادات النظام، منع تصحيح USB وإعادة ضبط المصنع، والتحكم في Wi-Fi وبيانات الهاتف والبلوتوث ونقطة الاتصال، وحظر المواقع الإباحية وVPN.
3. **منظومة الموقع الجغرافي والرادار التفصيلي (Ultra-Detailed Location & Geofencing)**:
   - خريطة تفاعلية حية بـ 4 أنماط (خريطة الشوارع، قمر صناعي، رادار تكتيكي، وضع ليلي) مع عرض مسار التحركات، نطاق الدقة، والمناطق الجغرافية.
   - بيانات موقع فائقة الدقة: خط العرض والطول (6 خانات عشرية)، الدقة بالمتر، السرعة الحالية (كم/س)، حالة الحركة، الارتفاع، زاوية البوصلة، والمسافة عن هاتف ولي الأمر.
   - إدارة السياج الجغرافي (Geofencing): إضافة وتعديل مناطق آمنة ومناطق محظورة/خطرة مع إجراءات تلقائية عند الدخول (تفعيل وضع الدراسة، قفل الهاتف، تحويل للصامت، أو إطلاق صافرة تحذير).
   - إعدادات متقدمة: رادار تنبيه تجاوز السرعة، كاشف الموقع الوهمي (Anti-Fake GPS)، وقفل الهاتف تلقائياً عند إيقاف GPS.
